# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project, please
report it responsibly by emailing **<security@xfa.tech>**.

Please **do not** open a public GitHub issue, pull request, or discussion for
security vulnerabilities — report them privately via the email above so the
issue can be addressed before it is disclosed publicly.

When reporting, please include as much detail as you can, for example:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- The affected version(s) of this provider and your Keycloak version.
- Any suggested remediation, if you have one.

## What to expect

- We aim to acknowledge your report within a few business days.
- We will keep you informed as we investigate and work on a fix.
- We will coordinate the timing of any public disclosure with you, and are happy
  to credit you for the report unless you prefer to remain anonymous.

## Scope

This policy covers the `xfa-keycloak-login-hint-mapper` provider in this
repository. For vulnerabilities in the XFA product or platform, please also use
**<security@xfa.tech>**. For issues in Keycloak itself, please refer to the
[Keycloak security policy](https://www.keycloak.org/security).

Thank you for helping keep XFA and its users safe.
